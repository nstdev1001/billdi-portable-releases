## 📦 Giới thiệu

Đây là kho phát hành **phiên bản portable (chạy trực tiếp, không cần cài đặt) của Billdi trên PC**.

**Billdi** là ứng dụng giúp nhóm bạn bè, đồng nghiệp chia chi phí chuyến đi: tạo chuyến, mời thành viên bằng link hoặc mã QR, ghi lại ai đã trả gì, Billdi tự tính xem ai cần chuyển cho ai bao nhiêu.

> [!NOTE]
> Sản phẩm chính thức của Billdi có tại **[billdivn.com](https://billdivn.com)**. Repo này chỉ chứa các bản build portable cho máy tính, không chứa mã nguồn ứng dụng.

## ✨ Tính năng chính

- 🧳 **Chuyến đi**: tạo, chỉnh sửa, hoàn thành chuyến; hỗ trợ danh mục, ghi chú và hình nền tuỳ chỉnh.
- 👥 **Thành viên**: thêm thủ công hoặc mời qua link, mã QR.
- 🧾 **Chi tiêu**: ghi lại người trả, nguồn tiền; nhập bằng câu nói tự nhiên và để AI tự điền thông tin.
- 💰 **Quỹ chung**: theo dõi tiền góp quỹ và các khoản chi từ quỹ.
- ⚖️ **Quyết toán**: tính trung bình mỗi người, số dư và danh sách chuyển khoản đã được tối giản.
- 🏦 **Thanh toán nhanh**: lưu mã QR ngân hàng để thành viên chuyển tiền cho nhau.
- 💱 **Đa tiền tệ**: tỷ giá quy đổi sang VND cập nhật trực tiếp.
- 🌐 **Song ngữ** Tiếng Việt / English, hỗ trợ chế độ tối.

## 💻 Vì sao dùng bản portable?

| | |
| --- | --- |
| ⚡ **Không cần cài đặt** | Tải về, giải nén (nếu có) và chạy ngay |
| 🔌 **Mang theo dễ dàng** | Chạy từ USB hoặc bất kỳ thư mục nào |
| 🧹 **Gọn gàng** | Không ghi vào registry; muốn gỡ chỉ cần xoá thư mục |
| 🔄 **Đồng bộ dữ liệu** | Đăng nhập cùng tài khoản để dùng chung dữ liệu với bản web và mobile |

## 🚀 Tải về và sử dụng

1. Mở trang **[Releases](https://github.com/nstdev1001/billdi-portable-releases/releases/latest)**.
2. Tải file dành cho hệ điều hành của bạn trong mục **Assets**.
3. Giải nén (nếu là file nén) và chạy file thực thi của Billdi.
4. Đăng nhập bằng Google, Facebook hoặc số điện thoại để bắt đầu.

> [!TIP]
> Lần đầu chạy trên Windows, nếu **SmartScreen** hiện cảnh báo, chọn **More info → Run anyway**. Chỉ tải Billdi từ trang Releases của repo này hoặc từ [billdivn.com](https://billdivn.com) để đảm bảo an toàn.
